# Inbox — photos en attente de traitement

Dépose ici les photos originales (HEIC/JPEG) envoyées depuis le Raccourci
Apple. Elles sont automatiquement converties (WebP), rattachées à un lieu/jour
puis intégrées dans `../data.js` et `../photos/` — ce dossier redevient vide
une fois le traitement effectué (`scripts/process-inbox.py` à la racine du
dépôt).
